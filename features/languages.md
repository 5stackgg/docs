# Languages

5Stack speaks your language. The interface is fully localized in **17
languages**: Arabic, Chinese (Simplified & Traditional), Danish, English, French,
German, Italian, Japanese, Korean, Polish, Portuguese (Brazil), Russian, Spanish,
Swedish, Turkish, and Ukrainian.

5Stack **auto-detects** your browser language on first visit. To change it, use
**Select Language** under **Settings → My Account**; your choice is saved to your
account.

In-game messages in the server chat show up in the player's language too.

## Default language

**Settings → Application → Language → Default language** is what visitors see
when their browser's language isn't one 5Stack has. Anyone can still choose
their own language.

## Help translate

Translations are community-driven. If something in your language reads wrong,
you can help improve it. See [Localization](/community/localization/) to
contribute.
