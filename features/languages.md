# Languages

5Stack speaks your language. The interface is fully localized in **17
languages**: Arabic, Chinese (Simplified & Traditional), Danish, English, French,
German, Italian, Japanese, Korean, Polish, Portuguese (Brazil), Russian, Spanish,
Swedish, Turkish, and Ukrainian.

5Stack **auto-detects** your browser language on first visit, and you can switch
languages any time, your choice is remembered.

Localization isn't limited to the web app: the **in-game CS2 plugin** is
translated into the same languages, so match messages in the server chat show up
in the player's language too.

## Help translate

Translations are community-driven. If your language is missing something. You can
help improve it. See [Localization](/community/localization/) to contribute.
