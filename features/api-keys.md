# API Keys

Generate personal **API keys** for programmatic access to 5Stack, pull your own
match and player data, or build integrations like Discord bots, dashboards, and
overlays.

## Managing your keys

- **Create** a key with a label so you remember what it's for.
- See each key's **created** date and **last-used** time at a glance.
- **Revoke** a key any time.

Treat a key like a password, anyone with it can act through the API as you. Copy
it when it's created and store it somewhere safe.

## Using the API

5Stack's API is GraphQL. See the [API docs](/advanced/api) for endpoints,
authentication, and examples.
